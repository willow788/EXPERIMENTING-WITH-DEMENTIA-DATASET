# Experimenting with Dementia Dataset

> **Status: Work in progress**
>
> This project is currently under development. The dataset, experiments, documentation, and analysis may change as the project evolves.

## Overview

This repository contains exploratory work involving a dementia-related dataset. The project is intended to support experimentation with data preparation, exploratory data analysis, feature investigation, and potential machine-learning applications.

The contents of this repository are not yet finalized, and results should be considered preliminary.

## Project Goals

The current goals of this project include:

- Understanding and documenting the dataset
- Cleaning and preparing the data for analysis
- Exploring patterns, relationships, and distributions
- Testing potential approaches for modeling or prediction
- Recording findings and improving the project structure over time

## Repository Contents

The repository is primarily written in **Python**. As development continues, this section will be updated with details about notebooks, scripts, datasets, and other project files.

## Getting Started

Clone the repository and navigate into the project directory:

```bash
git clone https://github.com/willow788/EXPERIMENTING-WITH-DEMENTIA-DATASET.git
cd EXPERIMENTING-WITH-DEMENTIA-DATASET
```

Create and activate a virtual environment:

```bash
python -m venv .venv
```

On macOS or Linux:

```bash
source .venv/bin/activate
```

On Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Install dependencies if a dependency file is available:

```bash
pip install -r requirements.txt
```
